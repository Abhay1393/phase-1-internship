# Phase 1 Internship Project

## 📌 Project Overview

This project is developed as part of the **Phase 1 Internship Program**.
The main objective of this phase is to understand the fundamentals of web development, set up the development environment, learn project structure, practice Git and GitHub, and create a basic **Hello World** project.

## 🎯 Objectives

The project focuses on:

* Setting up the development environment.
* Understanding HTML, CSS and JavaScript fundamentals.
* Understanding project structure and file organization.
* Learning Git and GitHub for version control.
* Creating and testing a simple Hello World project.
* Understanding basic development workflow.
* Preparing a foundation for advanced internship projects.

## 🛠️ Technologies Used

* **HTML5** – For creating the structure of the webpage.
* **CSS3** – For styling and responsive design.
* **JavaScript** – For adding interaction and functionality.
* **Git** – For version control.
* **GitHub** – For remote repository and project management.
* **Visual Studio Code** – Code editor.
* **Web Browser** – For testing the project.

## 🚀 How to Run the Project

### Step 1: Download or Clone the Repository

```bash
git clone https://github.com/Abhay1393/phase-1-internship.git
```

### Step 2: Open the Project

Open the project folder in **Visual Studio Code**.

### Step 3: Run the Project

Open `index.html` in a web browser.

You can also use the **Live Server** extension in Visual Studio Code.

## 👋 Hello World Milestone

The project contains a simple **Hello World** section to verify that the development environment is working correctly.

A button is provided to test JavaScript functionality.

When the button is clicked, JavaScript displays a confirmation message:

> JavaScript is working successfully.

This confirms that HTML, CSS and JavaScript are properly connected.

## 🔧 Git & GitHub Workflow

The project uses Git for version control.

Basic workflow used:

```bash

git commit -m "Complete Phase 1 project"
git branch -M main
git remote add origin https://github.com/Abhay1393/phase-1-internship.git
git push -u origin main
```
